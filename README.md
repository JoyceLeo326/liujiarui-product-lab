# 刘佳锐 · AI 产品实验室

十二个产品与研究项目的统一入口。访问者先选择观察视角，项目顺序随目标改变；每个条目都以具体人物、真实冲突和可验证结果说明产品，而不是只罗列技术栈。

## 本地运行

这是零构建依赖的静态站点。请通过任意静态服务器打开，例如：

```bash
npx serve .
```

验证：

```bash
npm test
npm run check
npm run audit:live
```

`audit:live` 会逐一访问目录中的正式入口，只输出状态、耗时和错误类型；若页面不可达、依赖受限的远程运行时资源，或出现凭据形态内容，命令会失败且不会回显命中值。

## 内容边界

- 项目目录以 `projects.json` 为唯一事实源。
- 私有仓库不展示源码入口；公开体验仅包含可发布的静态产物。
- 研究项目与上线产品明确区分，不将计划或示例表述为真实业务结果。
- 站点不收集或保存 AI API 密钥，核心目录不依赖远程 AI 服务。

## 发布

`main` 分支通过测试与敏感信息门禁后，由 GitHub Actions 发布至 GitHub Pages。所有字体、脚本、样式和图标均随站点发布。
